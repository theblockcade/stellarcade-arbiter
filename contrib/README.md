# contrib/

External, non-core contributions live here: additional example scripts,
alternative deployment blueprints, and small operational tooling that isn't
part of the arbiter's settlement-critical path.

Nothing that touches `src/entropy.ts`, `src/beacon.ts`, `src/settle.ts`,
`src/policy.ts`, or `migrations/` belongs in `contrib/` — see
[CONTRIBUTING.md](../CONTRIBUTING.md).
